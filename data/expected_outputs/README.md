# Примеры и будущие эталоны

`pasta.json`, `omelette.json` и `salad.json` — **синтетические примеры чернового Recipe**. Они созданы для проверки формата. Они не извлечены из видео и не сверены с реальными роликами.

Для подготовки эталонного набора:

1. Добавь соответствующие разрешенные MP4 по [инструкции](../input_videos/README.md).
2. Вручную выпиши только сведения, подтвержденные содержимым ролика.
3. Замени синтетический JSON разметкой и укажи проверяемый источник.
4. Проверь JSON через согласованный `Recipe` из `fropti-core-contracts`.
5. Зафиксируй происхождение видео и проверку разметки в `../input_videos/provenance.md`.

Сравнивай смысл полей, а не только текстовую идентичность: одинаковая инструкция может быть сформулирована по-разному. При этом пропущенные ингредиенты, неверные количества и выдуманные шаги должны считаться ошибками. Правила сравнения согласуй до оценки качества.
