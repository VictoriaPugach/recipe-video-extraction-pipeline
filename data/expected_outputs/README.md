# Синтетические примеры и ручные эталоны

`pasta.json`, `omelette.json` и `salad.json` — **синтетические примеры общего
Recipe 1.0.0**. Они созданы для проверки формата, не извлечены из видео и не
сверены с реальными роликами.

Ручные эталоны основного локального набора:

| Видео | Эталон |
| --- | --- |
| `shakshuka.mp4` | `shakshuka.json` |
| `plov.mp4` | `plov.json` |
| `tomatoChickpea.mp4` | `tomatoChickpea.json` |

`cake.json` и `butterChicken.json` относятся к дополнительным экспериментам с
`chocolateCake.mp4` и `butterChicken.mp4`. Источники, типы входа, длительности и
фактические результаты сравнения зафиксированы в
[../input_videos/provenance.md](../input_videos/provenance.md). Соответствующие MP4
включены в ветку; их размещение в наборе согласовано с ревьюерами.

При подготовке или исправлении эталона:

1. Вручную выпиши только сведения, подтвержденные содержимым ролика.
2. Неизвестные значения сохраняй как `null`; не добавляй сведения для заполнения
   полей. Хотя бы один ингредиент и один непустой шаг обязательны по Recipe 1.0.0,
   но схемная валидность не делает выдуманную инструкцию приемлемой.
3. Проверь JSON командой
   `.venv/bin/python -m fropti_core_contracts data/expected_outputs/*.json`.
   Контрактные тесты дополнительно проверяют файлы по JSON Schema.
4. Зафиксируй происхождение видео и ручную сверку в
   `../input_videos/provenance.md`.

Сравнение выполняется по
[метрике из рубрики приёмки](../../docs/evaluation.md#как-считать-совпадение-полей).
Поля и правила нормализации фиксируются до запуска оценки. Для каждого результата
нужно сохранить числитель, знаменатель, процент и список расхождений; отдельно
отметить сведения, не подтверждённые видео. Исключение свободных формулировок из
численной метрики не отменяет ручную проверку полноты и достоверности шагов.

Эти же файлы служат примерами границы трёх модулей: video extraction производит
объект целиком, cooking planner / batch cooking читает шаги и порции, shopping
list — ингредиенты и порции. Потребители не должны переименовывать поля или
создавать собственный вариант `Recipe`. Примеры не подтверждают готовность логики
планирования или списка покупок.
