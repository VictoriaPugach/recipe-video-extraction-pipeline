# Происхождение набора проверки

Основной набор содержит три ролика и закрывает все три типа входа: только
аудио — `shakshuka.mp4`, сочетание речи и надписей — `plov.mp4`, только текст —
`tomatoChickpea.mp4`. `chocolateCake.mp4` и `butterChicken.mp4` — дополнительные
эксперименты; они не заменяют основные сценарии демонстрации.

Все пять MP4 включены в ветку `video-extraction-mvp`; их размещение в
валидационном наборе согласовано с ревьюерами. Ниже зафиксированы доступные
источники и сведения о происхождении. Неизвестные автор, дата получения и
лицензия не выдумываются. Ручные эталоны и небольшие обезличенные результаты
запусков находятся в том же наборе данных.

Все длительности ниже лимита 180 секунд. Процент — результат заранее заданного
сравнения полей, а не самостоятельное доказательство смысловой правильности.
Каждый результат также нужно вручную проверить против видео: схемная валидность
не оправдывает выдуманные или слишком общие инструкции.

## Основной набор

### shakshuka.mp4 — только аудио

- Источник: https://www.youtube.com/shorts/U4lQPin-zis
- Доступные сведения: канал «Sara - Nutrient Matters», публикация 17.03.2024,
  название «When I don't want leftovers I make this single serve shakshuka».
- Лицензия и точная дата получения копии: не зафиксированы.
- Ручной эталон: `../expected_outputs/shakshuka.json`.
- Результат `POST /extract/upload`: `../../runs/shakshuka.upload.json`;
  сравнение 40/40 = 100,0%, PASS.

### plov.mp4 — сочетание речи и надписей

- Источник: https://www.facebook.com/watch/?v=1293244242771191
- Доступные сведения: страница «Milana Russian Wife» указана автором PR;
  название публикации, лицензия и точная дата получения не зафиксированы.
- Ручной эталон: `../expected_outputs/plov.json`.
- Последний локальный запуск `POST /extract/upload`: 51/60 = 85,0%, PASS.
  Зафиксированные расхождения: отсутствуют эталонные шаги 10/11, есть сдвиг
  или ошибка в длительностях шагов, заголовок `homemade plov` вместо
  `real homemade plov`. Соответствующий новый JSON ещё не добавлен в ветку.
- `../../runs/plov.upload.json` в текущем снимке относится к предыдущему
  запуску и даёт 53/62 = 85,4%; его нельзя выдавать за артефакт последнего
  результата 85,0%. Перед финальной сдачей заменить файл фактическим JSON
  последнего запуска и повторить сравнение.
- URL-запрос этого ролика через `/extract` сейчас не поддерживается: Facebook
  отсутствует в `ALLOWED_URL_HOSTS`. Проверка выполняется через upload или CLI
  с локальным файлом; это не доказывает поддержку Facebook URL.

### tomatoChickpea.mp4 — только текст

- Источник: https://www.youtube.com/shorts/fhphZcnJ3dA

## Аннотирование, сравнение и границы доказательств

- Автор ручной разметки: Gabri.
- Метрика: `scripts/compare_gold.py --exclude /source --absent-equals-null
  --skip-notes --skip-instructions`; порог — не меньше 80% для каждого видео.
- Ингредиенты сопоставляются по нормализованному имени. Исключение формулировок
  шагов не скрывает пропущенные и лишние шаги; `--absent-equals-null` не стирает
  поля полностью отсутствующего элемента списка.
- В ветке есть перечисленные выше `runs/*.upload.json` и отчёты для этих же
  файлов в `runs/comparisons/`; предыдущий Plov-отчёт явно назван
  `plov.previous-upload.txt`. Результаты CLI, успешные `runs/*.url.json`,
  обезличенные `transcript.txt`/`screen_text.txt`, новый JSON и отчёт Plov 85,0%
  ещё не приложены.
- 16.11.2026 на Docker-машине автора `scripts/test_egress.sh` успешно завершил
  все пять сетевых проверок, включая запрет редиректа на loopback и отсутствие
  прямого egress. Фактический `runs/controlled-egress.log` добавляется автором
  отдельно; окончательный security sign-off остаётся за ревьюером.
- Секреты, cookies, персональные данные и чувствительные логи в доказательства
  не включать. Результаты моков не выдавать за реальное извлечение.
