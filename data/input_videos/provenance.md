# Происхождение валидационного набора

Набор приёмки: 4 ролика, закрыты все три типа входа: только аудио —
shakshuka и cake (речь на русском), сочетание (речь и надписи) — plov,
только текст — tomatoChickpea («no-talking», рецепт в надписях, звук —
музыка). См. real-testing.md, таблицу типов.

В репозиторий коммитятся `manifest.json`, этот файл и эталоны в
`../expected_outputs/`. Медиафайл попадает в репозиторий только при
подтверждённом праве: лицензия CC-BY (с указанием автора и ссылки) либо
собственная запись. Доступность ролика в интернете сама по себе права
не даёт — правила в [README](README.md). До подтверждения MP4 хранятся
локально; для воспроизведения скачать ролик по ссылке из `manifest.json`
или запросить файлы у автора PR.
