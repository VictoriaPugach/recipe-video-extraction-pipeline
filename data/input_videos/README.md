# Тестовые видео

Реальные MP4 не предоставлены. Эта папка пока не содержит готового набора для проверки извлечения.

Для приемки добавь три коротких ролика с разрешенным использованием:

| Видео | Соответствующая разметка |
| --- | --- |
| `pasta.mp4` | `../expected_outputs/pasta.json` |
| `omelette.mp4` | `../expected_outputs/omelette.json` |
| `salad.mp4` | `../expected_outputs/salad.json` |

Эти имена предназначены для будущего набора. Имеющиеся JSON синтетические: их нужно заменить или проверить и скорректировать по фактическому содержимому видео.

Скопируй `manifest.example.json` в `manifest.json` и заполни для каждого видео источник, разрешение на использование, длительность и путь к разметке. Поставь `annotation_verified: true` только после сверки JSON с видео. В `provenance.md` дополнительно укажи автора видео, дату получения и автора ручной разметки. Каждый ролик должен длиться не больше 180 секунд.

Подбери разные источники информации: речь, надписи и их сочетание. Не загружай приватные материалы, чужие cookies или видео без разрешения на распространение. Доступность ролика в интернете сама по себе не дает права включить его в репозиторий.

Локальные MP4 нужны для воспроизводимой проверки извлечения. Они не подтверждают работоспособность скачивания с YouTube Shorts, Reels или RuTube: загрузчик проверяется отдельно на доступных разрешенных URL.
