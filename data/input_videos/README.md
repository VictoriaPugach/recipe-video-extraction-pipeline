# Видео для проверки

Ветка содержит пять MP4 с согласованным ревьюерами размещением в валидационном
наборе. `manifest.json` фиксирует источники, фактические длительности, типы входа
и ссылки на ручные эталоны; доступные сведения и результаты приведены в
[provenance.md](provenance.md).

Основной набор для демонстрации:

| Файл | Тип входа | Ручной эталон |
| --- | --- | --- |
| `shakshuka.mp4` | только аудио | `../expected_outputs/shakshuka.json` |
| `plov.mp4` | речь и надписи | `../expected_outputs/plov.json` |
| `tomatoChickpea.mp4` | только текст | `../expected_outputs/tomatoChickpea.json` |

`chocolateCake.mp4` и `butterChicken.mp4` — дополнительные эксперименты, не
обязательные для основной демонстрации. Все пять файлов доступны в этой папке
после checkout ветки; отдельно скачивать исходные ролики не требуется.

`pasta.json`, `omelette.json` и `salad.json` в `../expected_outputs/` остаются
синтетическими примерами контракта и не относятся к этому набору. Ручной эталон
должен содержать только сведения, подтверждённые видео; неизвестное сохраняется
как `null`. Поле `annotation_verified: true` означает ручную сверку эталона.
Не добавляй приватные материалы, чужие cookies или персональные данные. Каждый
ролик должен длиться не больше 180 секунд.

Локальные MP4 проверяют извлечение из файла, но не работоспособность скачивания
по URL. URL-путь проверяется отдельно на поддерживаемой платформе. Facebook Plov
в текущий `ALLOWED_URL_HOSTS` не входит и поэтому проверяется только как локальный
файл. Полный протокол и перечень оставшихся доказательств — в
[real-testing.md](../../docs/real-testing.md).

Отправь файл через `/docs` → **POST /extract/upload → Try it out** или из корня
репозитория:

```bash
scripts/upload.sh data/input_videos/shakshuka.mp4
.venv/bin/python -m src.main --file data/input_videos/shakshuka.mp4
```

HTTP-загрузка ограничена 100 МиБ. API возвращает валидированный `Recipe` либо
структурированную ошибку из [API reference](../../docs/api_reference.md). CLI
печатает рецепт и завершается с кодом `0`; при ошибке — `[код] сообщение` и код
выхода `1` (для видео длиннее лимита — `2`).
