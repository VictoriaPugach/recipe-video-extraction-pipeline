# API reference

Базовый адрес при локальном запуске: `http://localhost:8000`. Интерактивная документация — `/docs`, машиночитаемая схема — `/openapi.json`.

## GET /health

Проверяет доступность приложения и сообщает выбранный режим контракта.

```http
GET /health
```

```json
{"status": "ok", "contract_mode": "draft"}
```

В режиме общего пакета `contract_mode` равен `shared`. Этот endpoint не проверяет доступность видеоплатформ или моделей.

## POST /extract

Принимает **JSON в теле запроса**, а не query-параметр.

```bash
curl -i -X POST http://localhost:8000/extract \
  -H 'Content-Type: application/json' \
  -d '{"url":"https://www.youtube.com/shorts/EXAMPLE_ID"}'
```

| Поле | Тип | Обязательность |
| --- | --- | --- |
| `url` | Строка, корректный HTTP/HTTPS URL | Да |

`EXAMPLE_ID` служит плейсхолдером. Синтаксически допустимый URL не гарантирует поддержку платформы или доступность видео.

## POST /extract/upload

Принимает видеофайл в **multipart/form-data**, поле `file`. В Swagger UI (`/docs`) нажми **Try it out**, выбери файл и нажми **Execute**.

```bash
curl -i -X POST http://localhost:8000/extract/upload \
  -F 'file=@data/input_videos/pasta.mp4'
```

Файл `pasta.mp4` пока не включен в репозиторий: сначала добавь разрешенное видео или замени путь своим. Не задавай `Content-Type` вручную: клиент добавит multipart boundary.

| Поле | Тип | Обязательность |
| --- | --- | --- |
| `file` | Непустой файл до 100 МиБ включительно | Да |

Сервис сохраняет файл во временную папку под собственным именем, передает путь общему пайплайну и очищает папку после запроса, в том числе при ошибке. Определение формата медиа и длительности остается TODO. Прием непустого файла сам по себе не подтверждает, что это корректное видео.

## 200 OK — целевой успешный ответ обоих эндпоинтов

Ответ — сам объект `Recipe`, без дополнительной обертки. Для интеграции используется `Recipe` из `fropti-core-contracts`. Пока пакет не подключен, пример отражает только [черновую схему](data_schema.md):

```json
{
  "title": "Омлет",
  "servings": 1,
  "ingredients": [
    {"name": "Яйца", "amount": 2, "unit": "шт."},
    {"name": "Соль", "amount": null, "unit": null}
  ],
  "steps": ["Взбейте яйца с солью.", "Приготовьте омлет на сковороде."],
  "source_url": "https://www.youtube.com/shorts/EXAMPLE_ID"
}
```

Для загрузки с устройства черновой `source_url` равен `null`. Представление источника в общем пакете нужно согласовать до интеграции. Каркас пока не извлекает рецепт и не возвращает этот пример как результат запроса.

## Ошибки

| HTTP | Код или формат | Условие | Состояние каркаса |
| --- | --- | --- | --- |
| `400` | `video_too_long` | Длительность больше 180 секунд | Ветка реализована; реальные метаданные должен получать студент |
| `400` | `empty_file` | Загружен пустой файл | Работает |
| `413` | `file_too_large` | Загруженный файл больше 100 МиБ | Работает |
| `422` | Стандартный `detail` FastAPI/Pydantic | Нет `url`, неверный тип, URL или JSON; нет поля `file` при загрузке | Работает |
| `501` | `pipeline_not_implemented` | Вызвана незавершенная часть пайплайна | Текущий ответ для корректного URL или непустого файла в пределах лимита |

180 секунд допустимо; 180.1 секунды — уже превышение. Проверка должна происходить до тяжелого распознавания.

Структура прикладной ошибки:

```json
{
  "detail": {
    "code": "video_too_long",
    "message": "..."
  }
}
```

`message` предназначен для человека; клиент должен ориентироваться на HTTP-статус и `code`. Многоточие в примерах обозначает пояснение, точный текст которого не является контрактом. Ответ `422` использует стандартный список ошибок в `detail` и не имеет такой же структуры, как `400`, `413` и `501`.

Коды ошибок скачивания, таймаутов и невалидного ответа LLM нужно согласовать при реализации и добавить сюда вместе с тестами. Они пока не заявлены как работающие.

## Ограничения интеграции

API каркаса не реализует аутентификацию, квоты, очередь задач и сохранение результатов. Не публикуй его как готовый публичный сервис. Мобильный клиент отправляет ссылку или файл серверу; он не запускает Python-код и не получает серверные API-ключи.
