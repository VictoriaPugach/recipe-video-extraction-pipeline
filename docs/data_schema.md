# Схема Recipe

## Источник контракта

Все модули Fropti должны использовать общий `Recipe`:

```python
from fropti_core_contracts.models import Recipe
```

Точный адрес репозитория, версия пакета и его поля не предоставлены. [Относительная ссылка `fropti-core-contracts`](../../fropti-core-contracts) — ориентир, который нужно проверить, а не подтвержденный адрес зависимости.

## Два явных режима

| `CONTRACT_MODE` | Поведение |
| --- | --- |
| `draft` | Локальная черновая модель для запуска каркаса и синтетических примеров |
| `shared` | Импорт настоящего общего `Recipe`; пакет должен быть установлен |

Режим по умолчанию — `draft`. При `shared` нет скрытого перехода на локальную модель. Нельзя объявлять интеграцию готовой только потому, что JSON проходит черновую валидацию.

## Черновая модель

Это временный формат, **не подтвержденная схема `fropti-core-contracts`**.

| Поле | Тип | Ограничение |
| --- | --- | --- |
| `title` | string | Минимум один символ |
| `servings` | integer | Положительное число |
| `ingredients` | array of Ingredient | Минимум один элемент |
| `steps` | array of string | Минимум один элемент; каждая строка непустая |
| `source_url` | HTTP/HTTPS URL | Корректный URL |

`Ingredient`:

| Поле | Тип | Значение |
| --- | --- | --- |
| `name` | string | Непустое название |
| `amount` | number или null | Положительное количество, если известно |
| `unit` | string или null | Непустая единица, если известна |

`null` означает отсутствие сведений. Не подставляй ноль вместо неизвестного количества и не придумывай его. Схемная валидация проверяет форму данных, но не подтверждает, что ингредиенты и шаги действительно были в видео.

Черновик требует известного числа порций. Если его нельзя определить по ролику, не придумывай значение: согласуй с командой представление неизвестных порций в общем контракте. До этого такой ролик не должен получать успешный ответ с выдуманными данными.

Примеры находятся в [data/expected_outputs](../data/expected_outputs). Это синтетические данные для проверки схемы, не результаты обработки видео.

## Переход на общий пакет

1. Получи подтвержденный адрес и версию `fropti-core-contracts` у команды.
2. Добавь согласованный источник установки и закрепленную версию в `requirements.txt`; не передавай credentials через репозиторий.
3. Сверь поля и правила сериализации с реальным `Recipe`. Исправь преобразование результата LLM.
4. Обнови JSON-примеры, тесты, README, коллекцию Postman и эту страницу.
5. Установи `CONTRACT_MODE=shared` в окружении и проверь запуск, OpenAPI и успешный ответ.
6. Проверь каждый эталон через реальный `Recipe`, затем выполни сквозной тест с видео.

Согласованный пакет определяет конечный формат, даже если он отличается от приведенного здесь черновика.
