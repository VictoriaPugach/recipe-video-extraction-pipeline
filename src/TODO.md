# План реализации MVP (10–12 часов)

Каркас уже принимает URL и загруженный файл, проверяет пустой файл и размер, предоставляет CLI. Извлечение пока возвращает `501`. Пункты ниже относятся к оставшейся реализации; критерии готовности приведены в [рубрике](../docs/evaluation.md).

1. [ ] Изучить подключённый `Recipe` 1.0.0, валидатор и JSON Schema в `packages/fropti-core-contracts/`; использовать их в промпте LLM и интеграциях без создания отдельной модели.
2. [ ] Подготовить минимум три разрешённых реальных видео и ручные эталоны в `data/`; зафиксировать нормализацию и набор оцениваемых полей до прогона.
3. [ ] Реализовать безопасное получение метаданных URL и файла в `downloader.probe_duration`; отклонять видео длиннее 180 секунд до тяжёлых этапов.
4. [ ] Реализовать `downloader.download_video` с защитой от SSRF, проверкой редиректов, ограничениями размера и времени; использовать временные файлы с очисткой.
5. [ ] Реализовать извлечение аудио и STT в `extractors/stt.py`; закрепить модель, параметры и требования к ресурсам.
6. [ ] Реализовать выбор кадров в `extractors/frames.py` и OCR в `extractors/ocr.py`; определить частоту кадров и ограничения ресурсов.
7. [ ] Реализовать объединение STT/OCR через LLM в `llm/fusion.py`, валидацию общего `Recipe` и ограниченные повторы без выдумывания отсутствующих данных.
8. [ ] Соединить этапы в `pipeline.py` для URL и локального `Path`, сохранив работающие точки входа и очистку временных данных при успехе и ошибке.
9. [ ] Согласовать и реализовать обработку ошибок этапов в `api.py` и `main.py`; обновить API-документацию, Postman и пример клиента по фактическому поведению.
10. [ ] Дополнить тесты публичного поведения без API-ключей, выполнить `make test`, отдельно провести реальные сквозные проверки и приложить результаты по рубрике.

Все десять пунктов относятся к обязательному MVP. Для URL достаточно одной согласованной платформы и трёх воспроизводимых видео; локальная загрузка остаётся обязательной. Поддержку нельзя объявлять по одному частному успешному URL.

## Бонусы после MVP

- [ ] Добавить и отдельно протестировать другие платформы (YouTube Shorts, Reels, RuTube), не используя приватные cookies или обход ограничений доступа.
- [ ] Измерить задержку и ресурсы, затем при необходимости спроектировать отдельный асинхронный API заданий.
- [ ] Добавить GPU-профиль, кэширование или публикацию `fropti-core-contracts` только с воспроизводимой установкой и версионированием.
- [ ] Интегрировать сохранение, UI или каталог продуктов в отдельных модулях, не расширяя ими `Recipe` 1.0.0.
